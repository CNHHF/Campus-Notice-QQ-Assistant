自动推送与全局规则

只影响自动推送，查询与手动选择推送仍可使用。群订阅同时受这些规则限制；恢复后仅处理仍在有效期且未推过的通知。

定时抓取

最低 10 分钟，最长 180 分钟。微信与 QQ 共享这份抓取数据；QQ 的每分钟检查只读本地数据库。保存不立即抓取或推送，运行中的调度最多 5 秒读取新设置；缩短间隔后如已到期，将进入正常抓取轮次。

连接你的 QQ 机器人

使用支持 OneBot v11 的 QQ 客户端。此服务独立运行，保持现有微信链路。

账号与模型

Key 仅保存于本机运行配置，不回传到页面。自动通知推送无需 Key。

接入步骤

  1. 安装并登录 QQ 客户端

    支持 OneBot v11 的客户端，例如 NapCat。使用备用 QQ，由你本人扫码。

  2. 配置两个 HTTP 通道

    HTTP 服务端用于发消息，HTTP 客户端用于上报消息。都使用本机地址与 Token。

  3. 保存账号并检查连接

    填写机器人 QQ 号，检查通过后加入测试群，再打开群自动推送。

示例含接入 Token，只交给本机 QQ 客户端，勿上传仓库。接收消息格式必须设为 array。
