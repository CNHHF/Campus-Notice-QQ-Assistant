# 东方知讯 · 校园通知 QQ 助手（官方查询版）

作者：HHF。本分支 `official-qq-query-desktop` 使用腾讯官方 QQ Bot，独立运行通知采集、DeepSeek 检索、桌面管理和会话筛选，无需其他 AI 项目或 QQ 客户端。

**可用：** 自动采集学校通知、桌面浏览与筛选预览、群内 @ 查询、自然语言检索、按会话保存来源/分类/关键词。

**不可用：** 无人触发的定时群推送。腾讯官方文档注明主动推送能力自2025年4月21日起不再提供；本分支禁用主动发送和发送调度。连接在线只代表可接收与回复消息。

## 使用

1. 按 [独立部署指南](qq-service/README.md) 配置自己的 QQ Bot 与 DeepSeek 凭据。
2. 桌面“会话与订阅”新增并启用会话筛选，可先预览匹配内容，保存不发消息。
3. 群内发送 `@机器人 查看订阅`，返回按已保存规则匹配的最近最多5条通知；可重复查询，不是未读队列。
4. 也可发送 `@机器人 最新通知`、`@机器人 查通知 奖学金`；筛选命令需先创建会话筛选，普通查询不需要。

采集默认60分钟，维护不手工触发抓取。学校原文链接保留；筛选预览和会话筛选排除招聘等内容，普通查询仍可找历史。微信/OpenClaw默认停用。原有回执、基线及账号设置保留，不自动重发。

NapCat版保持在 `main`，[旧版资料](docs/napcat-legacy.md)仅供该版本参考。两种渠道的账号、群标识和发送记录不能互换。桌面安装包接管已有部署，不是包含Python和采集器的全组件离线安装包。
