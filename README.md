# 东方知讯 · 校园通知 QQ 助手 v1.3.0

作者：HHF。此版本使用 NapCat / OneBot，提供 QQ 通知查询、自动推送、DeepSeek 检索、手动分发和 Windows 桌面管理。微信接入、授权、发送和 OpenClaw 运行依赖已移除。

## 部署

1. 安装 Python 3.12+，准备本项目和通知采集组件 `school-radar-pkg/school-radar`。
2. 执行 `powershell -NoProfile -File .\qq-service\setup.ps1`，创建独立环境并安装本地 QQ 二维码渲染依赖。重跑保留既有设置。
3. 安装并配置 NapCat / OneBot。使用自己的 QQ 账号与接口令牌，不共享他人的凭据。
4. 双击 `start-all.bat` 或安装桌面启动器，接入设置中完成 QQ 登录、接口和 DeepSeek 配置。
5. 访问与群管理中配置允许查询的群及订阅来源/分类。首次启用自动推送建立历史基线，避免补发。

管理页 http://127.0.0.1:8788；通知工作台 http://127.0.0.1:8765。采集默认60分钟，QQ每分钟只读本地通知库。采集调度独立位于 `bridge/bridge.py`，只采集、不发任何消息；管理服务负责 QQ 发送。

## 功能

- 群内 @ 查询奖学金、补考和竞赛等通知；上下文追问详情。
- 每群选择来源和分类，新增通知单行附原文链接，招聘等按全局规则过滤。
- 手动选择内容、预览接收对象后发送；不确定回执保留、不自动重发。
- 桌面浏览、阅读、收藏、采集状态和 QQ 登录，二维码仅本地生成。
- 模型凭据只来自本项目配置或 `DEEPSEEK_API_KEY`，不读取其他应用凭据。

旧版本和官方查询版分别保留在原分支及标签中；此版本分支 `release/v1.3.0-qq-only`，标签 `v1.3.0`，不覆盖旧版本。官方QQ查询版与NapCat版不能混用渠道标识及发送记录。

## 升级

先备份原配置、通知库和发送数据库；不要清空 `service.db` 或重新初始化已用群。将原采集间隔和QQ过滤规则迁移到 `bridge/bridge-config.json`，不要复制旧渠道凭据。旧发送记录和私密配置留在本机备份，升级不删除账号文件，也不会卸载用户其他应用。维护重启使用 `--wait-first-round`，不立即抓取。

桌面安装包仅安装启动器和页面，需要已有项目、Python、NapCat与采集器，不是全组件离线包。[QQ服务说明](qq-service/README.md) / [桌面说明](desktop/README.md)。发布说明见 [CHANGELOG](CHANGELOG.md)。
